Privacy Policy

PA Bud — Chrome extension for Power Automate
Effective date: July 20, 2026

Short version: this extension does not collect, store, transmit, or share any data about you. Everything it does happens inside your own browser, on Power Automate pages, using your existing Microsoft login. Nothing ever leaves your machine.

What the extension does

PA Bud runs only on Microsoft Power Automate pages (make.powerautomate.com and flow.microsoft.com). It reads the flow run history shown on the page and retrieves failure details for failed runs by calling the same Microsoft Power Automate API the portal itself uses, authenticated by the session you are already signed in with. The error details are displayed directly in the page.

Data collection

None. The extension does not collect, log, or transmit:

  • personal information or identifiers of any kind
  • your flows, runs, error messages, or any business data
  • browsing activity, analytics, or telemetry
  • credentials or authentication tokens (your session token is used in-memory, within the page, solely to call Microsoft's API on your behalf, exactly as the portal does)

Data storage

The only thing the extension stores is your "Failed only" filter preference, kept in your browser's local storage on the Power Automate site. It never leaves your browser and is removed if you clear site data or uninstall the extension.

Third parties

The extension communicates exclusively with Microsoft's Power Automate service, and only in response to your actions on Power Automate pages. There are no third-party services, no external servers, no analytics providers, and no advertising of any kind. All code ships inside the extension package; nothing is loaded remotely.

Permissions

The extension requests access only to Power Automate pages, which it needs to display error details in the run history. It requests no other browser permissions — no access to your other tabs, history, bookmarks, or any other site.

Changes to this policy

If a future version of the extension ever changes how it handles data, this policy will be updated before that version is published, and the extension's store listing will reflect it.
